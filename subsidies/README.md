# Subsidies

Deze map bevat subsidie- en fondsenwervingsstukken voor Velo Vital.

## Structuur

- `2026/aanvragen/` - per subsidieaanvraag een eigen map met alle stukken.
- `2026/bronmateriaal/` - algemene projectplannen, huisstijl en begrotingsmateriaal dat voor meerdere aanvragen gebruikt kan worden.

## Status bijhouden

Gebruik `2026/aanvragen/STATUS.md` als centraal overzicht. Zet daarin per aanvraag:

- status: voorbereid, ingediend, toegekend, afgewezen, afgerond;
- gevraagd bedrag;
- toegekend bedrag;
- datum aanvraag;
- datum besluit;
- korte opmerking of vervolgstap.
